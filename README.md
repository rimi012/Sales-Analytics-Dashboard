# Sales Analytics Dashboard

## 📊 Project Overview

An end-to-end sales analytics project focused on analyzing revenue
performance, target achievement, account manager performance, and
yearly sales trends.

The project combines **Excel, MySQL, and Power BI** to transform sales
data into actionable business insights.

## 🛠️ Tools Used

- **Excel** – Data preparation and initial analysis
- **MySQL** – Data querying and performance analysis
- **Power BI** – Interactive dashboard and data visualization

## 🎯 Objectives

- Analyze revenue targets against actual achievements
- Evaluate account manager performance
- Identify top-performing sales representatives
- Analyze yearly revenue and gross-margin performance
- Track target gaps and achievement percentages
- Analyze quarterly and monthly sales trends

## 🔍 SQL Analysis

MySQL was used to perform analysis on sales performance data, including:

- Overall revenue target vs. achievement
- Account manager performance
- Account manager ranking
- Top-performing account managers
- Target achievement analysis
- Year-wise revenue performance
- Gross-margin performance
- Monthly sales performance
- Expected vs. committed vs. closed sales
- Performance categorization

### SQL Concepts Used

- Aggregate Functions
- `GROUP BY`
- `ORDER BY`
- `HAVING`
- `CASE WHEN`
- `UNION ALL`
- Window Functions
- Calculated Metrics

The complete SQL queries are available in [`sales_analysis.sql`](sales_analysis.sql).

## 📈 Power BI Dashboard

The Power BI dashboard provides interactive analysis of:

- Total Revenue
- Annual Revenue Target
- Revenue Achievement %
- Closed Deals
- Gross Margin
- Account Manager Performance
- Revenue Target Achievement
- Year-wise Performance

## 💡 Key Insights

The analysis helps identify:

- High- and low-performing account managers
- Revenue achievement against annual targets
- Year-over-year sales performance
- Gross-margin achievement
- Monthly and quarterly sales trends
- Areas with significant target gaps
